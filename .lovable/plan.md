# تطوير لوحة التحكم (Dashboard)

اللوحة الحالية عبارة عن 4 كروت KPI + قائمة حجوزات + قائمة أسطول — بدون تسلسل بصري، بدون رسوم بيانية، ولا اختصارات عمل. سنعيد بناء الصفحة بالكامل مع الحفاظ على نفس المنطق الخلفي (`loadDashboard`) وتوسيعه قليلاً.

## الهوية البصرية

- الاعتماد على ألوان الشعار: **Navy `--primary`** كخلفية للـ Hero والبطاقات المميّزة، **Amber `--accent`** كلون تحفيزي للأرقام والأزرار الثانوية.
- الحفاظ على tokens الحالية في `src/styles.css` — لا ألوان hardcoded.
- استخدام `Mada` للعناوين و `Cairo` للنصوص (موجود مسبقاً).

## البنية الجديدة

┌─────────────────────────────────────────────────────────┐

│  [إجراءات سريعة: بيع تذكرة · رحلة جديدة · منفستو]      │
└─────────────────────────────────────────────────────────┘

┌───────────┬───────────┬───────────┬───────────┐
│ حجوزات    │ رحلات     │ أسطول     │ إشغال     │
│ اليوم     │ نشطة      │ جاهز      │ متوسط %   │
│ + مقارنة  │ + مقارنة  │ + حالة    │ + شريط    │
└───────────┴───────────┴───────────┴───────────┘

┌──────────────────────────────┬──────────────────────┐
│ إيرادات آخر 7 أيام (Area)    │ حالة الأسطول         │

## التغييرات على الكود

### 1. `src/routes/_authenticated/dashboard.tsx` (إعادة كتابة كاملة)

- **Hero band**: div بخلفية `bg-primary text-primary-foreground` مع gradient خفيف، يحتوي الترحيب + إيرادات اليوم كرقم ضخم (text-5xl display) + 3 أزرار quick action (Link إلى `/pos`, `/trips`, `/manifest`).
- **KPI Grid**: 4 بطاقات محسّنة — كل بطاقة تحوي أيقونة ملوّنة + الرقم + دلتا اليوم مقابل الأمس (سهم أخضر/أحمر) + خط sparkline صغير مبني بـ SVG بسيط (لا حاجة لمكتبة).
- **Revenue chart (7 أيام)**: SVG Area chart مبني يدوياً بـ `path` — بلون `--primary` مع تعبئة `--primary-soft`. يحسب من استعلام إضافي:
  ```ts
  supabase.from("bookings")
    .select("amount, created_at, status")
    .gte("created_at", <منذ 7 أيام>)
  ```
  ثم يُجمَع في الـ client حسب اليوم.
- **حالة الأسطول**: Donut SVG (3 قطاعات: جاهزة/صيانة/متوقفة) + قائمة أفقية بالأرقام والنِسَب.
- **آخر الحجوزات**: تحويل من `<ul>` بسيطة إلى جدول (`<table>`) بـ 5 أعمدة (راكب، خط، مقعد، مبلغ، حالة/وقت). شارات الحالة بألوان semantic (`success`, `warning`, `destructive`).
- **الرحلات القادمة**: قسم جديد يستعلم `trips` (القادمة اليوم/غداً) ويعرض بطاقة صغيرة لكل رحلة مع شريط إشغال (bar) بلون accent.
- **حالات فارغة محسّنة**: illustration بسيطة بـ SVG + CTA زر ينقل للصفحة المناسبة (مثلاً "أضف أول حافلة" → `/buses`).

### 2. توسيع `loadDashboard`

يبقى نفس `queryKey: ["dashboard"]` مع refetch كل دقيقة. يُضاف:
- `revenueSeries`: مصفوفة `{ day: string, revenue: number, bookings: number }` لآخر 7 أيام.
- `yesterdayRevenue` و `yesterdayBookings` لحساب الدلتا.
- `upcomingTrips`: أقرب 4 رحلات مجدولة (`status=scheduled`, `departure_at >= now`) مع عدد المقاعد المحجوزة / السعة.

### 3. لمسات التنسيق

- Container: `max-w-7xl mx-auto` مع padding responsive.
- Rounded corners موحّدة (`rounded-2xl`), ظلال `shadow-card` (موجود).
- Grid responsive: `grid-cols-1 md:grid-cols-2 xl:grid-cols-4` للـ KPI؛ `lg:grid-cols-3` للقسم الأوسط (chart يأخذ 2/3).
- الأرقام المالية دائماً `.tabular` (utility موجود).
- لا تعديل على `app-shell.tsx` أو الـ routing.

## خارج النطاق

- لا تغيير على الصفحات الأخرى (bookings/pos/trips/manifest).
- لا تعديل على قاعدة البيانات — نستخدم الجداول القائمة فقط.
- لا إضافة مكتبات رسم (نبني الرسوم بـ SVG يدوياً لتبقى الحزمة خفيفة).
